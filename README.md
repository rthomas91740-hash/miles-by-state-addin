# Miles by State

A MyGeotab add-in that shades a US map by the miles each state accounted for, using fuel tax (IFTA) jurisdiction records from the database you are logged into. Pick a period (last quarter, this quarter, last month, last 30 days, or custom dates) and the map, ranked list and total update.

Miles are totals inside each state. For tax filing, use Geotab's official Fuel Tax Report.

## Install in MyGeotab

1. Administration > System > System Settings > Add-Ins.
2. Turn on "Allow unverified add-ins" if it is off, then click New Add-In.
3. Paste the contents of `config.json` into the Configuration tab and save.
4. Refresh MyGeotab. "Miles by State" appears under the Activity menu.
